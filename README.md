# CLI Менеджер Паролей на Python

Консольное приложение для безопасного хранения, генерации и управления паролями с использованием локального шифрования и базы данных SQLite3.

## Особенности и безопасность
* **Мастер-пароль:** Вход в систему защищен мастер-паролем. В базе данных хранится только его криптографический хэш SHA-256, сам пароль в открытом виде нигде не записывается.
* **Шифрование данных:** Все пароли аккаунтов шифруются с помощью алгоритма Fernet (библиотека `cryptography`).
* **Локальный ключ:** Ключ шифрования генерируется при первом запуске и хранится в скрытом локальном файле `.key`. Без этого файла расшифровать базу данных невозможно.
* **Защита от утечек:** База данных `passwords.db` и файл ключа `.key` автоматически добавлены в исключения Git через `.gitignore`.

## Доступные команды в меню
* `add` — добавить новую учетную запись (интерактивный ввод названия, логина и пароля).
* `get` — извлечь и расшифровать пароль по названию сервиса (требуется повторное подтверждение мастер-пароля).
* `list` — вывести список всех сохраненных сервисов и логинов в виде аккуратной таблицы.
* `delete` — безвозвратно удалить запись из базы данных по её названию.
* `new` — запустить интерактивный генератор надежного случайного пароля с настройкой длины и используемых символов.
* `exit` — безопасный выход из приложения.
